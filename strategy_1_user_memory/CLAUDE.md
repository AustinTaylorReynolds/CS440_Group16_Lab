# Personal CLAUDE.md (Strategy 1, tier 2: User Memory)

This is an example of personal preferences. Copy it to `~/.claude/CLAUDE.md` and it applies to every project on
your machine. Keep it about you and how you like to work. Rules about this lab live in the repository's
`CLAUDE.md`, not here.

## How I like to work
- Make small changes and run the code after each one.
- Explain what you changed in plain language, and lead with the result.
- If something is ambiguous, ask me one clear question instead of guessing.

## Code style I prefer
- Python: snake_case, a one-line docstring on every function, and comments that say why, not what.
- Named constants instead of magic numbers.
- Standard library first. Ask before adding a dependency.

## Safety habits
- Do not delete or overwrite my files without asking.
- Do not run commands that need the network or install packages without asking.
- Tell me when a check fails. Do not quietly work around it.
